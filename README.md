# # CodeAlpha Data Analytics Tasks

This repository contains my completed Data Analytics internship tasks for CodeAlpha.

## Tasks Included

### Task 1 - EDA & Data Cleaning
Performed Exploratory Data Analysis (EDA) and data cleaning on the Superstore dataset.

Topics covered:
- Data cleaning
- Missing values analysis
- Duplicate checking
- Feature engineering
- Correlation analysis
- Outlier detection

### Task 2 - Data Visualization
Created visualizations and business insights using charts and graphs.

Topics covered:
- Sales by category
- Profit analysis
- Regional sales performance
- Sales trends over time
- Profit vs Discount analysis

### Task 3 - Sentiment Analysis
Performed sentiment analysis on Amazon customer reviews using NLP techniques and VADER.

Topics covered:
- Text cleaning
- Sentiment classification
- Data visualization
- WordCloud generation
- Customer review analysis

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- WordCloud
